## 怎么发现的

不是看出来的，是读代码读出来的。旧版首页写着「28 款开发实用工具」，逐个翻实现时撞见了这段：

```js
function genQR(){
  // ...
  let seed = 0;
  for (let i = 0; i < text.length; i++) seed = (seed * 31 + text.charCodeAt(i)) & 0xffffffff;
  function rng(){ seed = (seed * 1103515245 + 12345) & 0x7fffffff; return seed / 0x7fffffff }
  for (let y = 0; y < n; y++)
    for (let x = 0; x < n; x++) {
      if ((x<7&&y<7)||(x>=n-7&&y<7)||(x<7&&y>=n-7)) continue;
      if (rng() > 0.5) ctx.fillRect(x*cell, y*cell, cell, cell);   // ← 随机撒格子
    }
  // 三个角画上定位图案
}
```

它用文本算了个种子，然后**伪随机**往画布上撒黑白格子，再把三个角的定位图案画上去。视觉上完全像二维码，实际扫不出来。画布中间还印着「简易QR」四个字——大概是当时留下的诚实标记，但没人会去放大看。

顺着查下去，同类问题一片：

| 功能 | 界面承诺 | 实际实现 |
|---|---|---|
| 二维码生成 | 生成二维码 | 伪随机撒格子，扫不出来 |
| 二维码解析 | 上传识别内容 | 写死一句「演示版，建议用在线工具」 |
| MD5 | MD5/SHA1/256/512 | 输出「浏览器原生不支持」 |
| 文本 Diff | 绿=新增 红=删除 | 逐行下标对比，且强制 `color: var(--text)`，根本没有颜色 |
| Cron 解析 | 下次 5 次执行时间 | 只往后推 5 分钟，填 `0 9 * * *` 必然显示「无法计算」 |

## 为什么难发现

这类缺陷有个共同特征：**语法全对，界面完整，交互正常，按钮有反馈**。

Diff 那个更隐蔽——中间插一行，后面所有内容都会被标成「有差异」，但界面上确实输出了对比结果，不仔细看会以为是文本真的改了。Cron 那个也一样，`*/5 * * * *` 是能算出结果的，只有填真实业务表达式才会露馅。

单元测试也拦不住。断言「调用 `genQR` 后画布上有黑色像素」会通过，断言「返回了字符串」也会通过。要拦住它，断言必须指向**外部可验证的事实**：把生成的图用解码器扫一遍，看能不能还原出原文。

## 怎么修

原则很简单：**做不真的功能就别做**，比留个假的强。

真有算法需求的，一律换成成熟库。这些都不大，自托管之后按需加载：

- 二维码生成 → `qrcodejs`（20KB）
- 二维码识别 → `jsQR`（257KB，懒加载）
- MD5 → `blueimp-md5`（3.7KB，Web Crypto 确实不支持 MD5）
- 文本 Diff → `jsdiff`（24KB，Myers 算法）
- Cron → `croner`（18KB，能算真实的未来执行时间）

换完之后我在检查脚本里加了一条回归断言，专门防这个坑复发：

```js
// 二维码实现里不允许出现 Math.random
if (/Math\.random|rng\(\)/.test(qrImpl)) fail('二维码仍在用随机数伪造');
```

## 文案矛盾是同一类病

还有个更隐蔽的问题。首页、页脚、导航页、片段页都写着「数据存在本地」「纯静态」「不上传任何服务器」，但代码里：

```js
async function renderNav(){
  const data = await apiRequest('/api/nav');   // ← 打后端
}
```

书签、短链、片段、留言板全部在调后端 API，**一个 localStorage 都没有**。设置页自己也承认「云盘、短链接、网址导航、代码片段、留言板需要后端支持……存储在云端」。

首页在说谎。而且这句话读起来特别顺，顺到你不会去怀疑它。

现在检查脚本里也有一条：

```js
if (/数据存在本地|不上传任何服务器|纯静态/.test(code)) fail('文案与实现矛盾');
```

只允许工具箱单独声明「本地运行」——那个是真的，32 个工具确实一个请求都不发。

## 一句话总结

判断功能真假，别看它有没有界面、有没有输出，看**输出能不能被外部独立验证**。二维码拿去扫，哈希拿已知答案对，Diff 拿 git diff 比，Cron 拿 crontab.guru 核。验证不了的功能，宁可砍掉。
